ASHLEY STUDIO

Premium Websites. Digital Experiences. Built With Purpose.

Ashley Studio is a premium website consultation platform designed for businesses, brands, creators, and professionals who need a modern website or want to improve their existing online presence.

The website combines elegant visual design, smooth animations, responsive layouts, and a simple consultation process to turn potential clients into project inquiries.

---

✦ Features

- Premium luxury-inspired visual design
- Fully responsive mobile and desktop layout
- Smooth scrolling experience
- GSAP-powered animations
- Scroll-triggered reveal animations
- Hero section with cinematic visual effects
- Interactive portfolio/project section
- Website consultation form
- WhatsApp contact integration
- Email consultation option
- Direct phone-call option
- Mobile navigation menu
- Responsive project cards
- Floating WhatsApp button
- Mobile horizontal-overflow protection
- Clean and modern user experience

---

🛠️ Built With

- HTML5 — Page structure and semantic markup
- CSS3 — Styling, responsive layouts, animations and visual effects
- JavaScript — Interactions and form handling
- GSAP — High-quality animations
- ScrollTrigger — Scroll-based animation effects
- Google Fonts — DM Sans & Playfair Display

---

📱 Responsive Design

The website is designed to work across:

- Mobile phones
- Tablets
- Laptops
- Desktop screens

Special attention was given to mobile navigation, spacing, typography, project layouts, and horizontal overflow.

---

🎬 Animation

GSAP and ScrollTrigger are used to create:

- Hero entrance animations
- Scroll reveals
- Image scaling
- Background parallax effects
- Section transitions
- Smooth visual movement throughout the page

The animations are intentionally subtle enough to maintain usability while giving the website a more premium feel.

---

📩 Consultation Form

The consultation form currently uses a "mailto:" workflow to prepare an email containing the client's submitted information.

For fully automatic form submissions without opening an email application, the project can later be connected to a backend or form-processing service.
